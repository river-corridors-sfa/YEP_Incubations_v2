# Data and scripts associated with "Sediment inundation history influences oxygen consumption more strongly than dissolved pyrogenic organic matter"

Vanessa A. Garayburu-Caruso*, Robert E. Danczak, Viviana Freire Zapata, Xia Gillespie, Alyssa Radakovich, Lupita Renteria, James C. Stegen, Nicholas Ward, Jianqiu Zheng, Allison N. Myers-Pigg*

Submitted to Biogeochemistry (in revision).

## Summary

This repository is associated with the manuscript "Sediment inundation history influences oxygen consumption more strongly than dissolved pyrogenic organic matter" (Garayburu-Caruso et al., in revision). It contains the input data, R scripts and outputs used to estimate biotic (Vmax) and abiotic (kL) components of O2 consumption from dissolved oxygen time series, test the effects of sediment inundation history (previously dry vs wet) and burned vs unburned dissolved organic matter (DOM), and characterize post-incubation DOM chemistry with FT-ICR MS. The scripts reproduce main-text Figures 2–3, Figures S1–S3, Tables S1–S4 and Data S1.

Underlying data are archived through ESS-DIVE as the Pyrogenic Organic Matter Laboratory Experiment data package (Gillespie et al., 2025). For details on how to navigate data packages generated by this project, see https://data.ess-dive.lbl.gov/portals/PNNLRiverCorridorSFA/About.

At the top level, the repository is organized into the following folders:

1. `data/v3`: the published ESS-DIVE data package v3 (Gillespie et al., 2025; doi:10.15485/3001969). Never edited.
2. `data/v4`: notes on the corrected files that will go into data package v4. See `data/v4/CHANGES.md` for what changed and why.
3. `data/working`: inputs that are not part of the data package yet (corrected water mass, respiration rates, NPOC/TN, and the merged DO time series and FireSting mapping with the H1/U1 start-time fix).
4. `src`: R scripts. Every script reads its inputs through `src/00_data_paths.R`, which lists exactly which file (v3, v4 or working) each input comes from.
5. `outputs`: figures, tables, statistics and model outputs regenerated by the scripts.

The `src` folder contains:

1. `00_data_paths.R`: single list of input files; stops with an error if any is missing.
2. `00_plot_style.R`: treatment names, colors and symbols shared by every figure and table.
3. `01_model_DO.R`: least-squares fits of kL and Vmax for each microcosm at 12 fixed Km values, a refit using only DO ≥ 2 mg/L, and Figure S2.
4. `02_model_mcmc.R`: MCMC posteriors of kL and Vmax at the seven Km values in the Sihi et al. (2020) range, convergence diagnostics, and Figure S3. Uses `mcmc_sampler.R`.
5. `03_stats.R`: Mann–Whitney, Kruskal–Wallis and Dunn tests, and bootstrap interaction tests.
6. `04_fig1_km_sensitivity.R`: Figure 2 (Vmax and kL across Km) and the full-range Km figure. The file name keeps its old figure number.
7. `05_fig_total_O2.R`: measured total O2 consumption by DOM treatment.
8. `06_fticr.R`: FT-ICR MS formula filtering, NMDS, Wd* and Tw2 tests, dispersion, intensity-weighted AI_mod and NOSC, and Figure 3.
9. `07_water_controls.R`: water-only (no sediment) controls and Figure S1.
10. `08_tables.R`: Tables S1–S4 and Data S1.

## Running the scripts

Run the scripts from the repository root (open `YEP_Incubations_v2.Rproj` in RStudio, or call `Rscript src/<script>.R` from the root), in this order:

**01 → 02 → 03 → 04–08**

01, 02 and 03 each read the outputs of the previous step. Scripts 04–08 need 01–03 but not each other, so they can run in any order. The MCMC outputs from 02 are included in `outputs/modeling/mcmc/`, so 03–08 can be rerun without rerunning 02, which takes several hours. To split 02 across sessions, give Km values on the command line and then combine:

```
Rscript src/02_model_mcmc.R 0.13 0.2
Rscript src/02_model_mcmc.R 0.3 0.51
Rscript src/02_model_mcmc.R 0.75 1 1.22
Rscript src/02_model_mcmc.R combine
```

### Packages

Install the CRAN packages:

```r
install.packages(c("tidyverse", "vegan", "patchwork", "rstatix",
                   "deSolve", "minpack.lm", "posterior", "remotes"))
```

`06_fticr.R` also needs WdStar (Wd* and Tw2 tests; Hamidi et al. 2019; Alekseyenko 2016), which is not on CRAN. Install it from GitHub:

```r
remotes::install_github("alekseyenko/WdStar")
```

On Windows, installing from GitHub may need [Rtools](https://cran.r-project.org/bin/windows/Rtools/) for your R version.
